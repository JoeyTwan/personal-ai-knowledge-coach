# 02 · 页面结构

## 1. 首页（Home）

**顶部**：一句自然语言入口「今天想学什么，或者有什么问题？」，支持文字与语音。

**中间**：今日知识状态

- 最近新增知识
- 最近建立的关联
- 待巩固知识
- 本周学习情况
- 一个重要知识断层
- 一个值得继续研究的方向

**下方**：今日 / 本周复习卡片（预计 10 分钟、5 个知识、8 道题）。

设计基调：安静、极简，像「我打开了私人 AI 助手」，不做复杂数据看板。

## 2. 记录 / 共创页（Record）

- 输入区（文字 / 语音）
- AI 讨论区（对话流：AI 追问、澄清、纠正）
- 共识确认区：AI 生成最终知识预览，按钮「收录 / 继续讨论 / 修改后收录 / 放弃」

## 3. 知识库列表页（Knowledge List）

- 搜索框（关键词 + 语义）
- 筛选器：分类、时间、来源、掌握状态
- 知识卡片：标题、核心结论、分类、掌握状态、更新时间
- 搜索结果不只显示标题，要说明「为什么相关」

## 4. 知识详情页（Knowledge Detail）

- 标题
- 核心结论（易懂语言）
- 详细解释（按用户认知层级展示）
- 来源（来源 + 时间）
- 时间（首次记录 / 最近更新）
- 相关知识（前置 / 相关 / 延伸 / 可解决问题 / 相关工作场景）
- 当前掌握（理解 / 应用等维度）
- 操作：编辑、与 AI 重新讨论、标记过时、归档、删除、开始复习

## 5. 知识网络页（Graph）

- 按主题查看
- 查看关联关系
- 查看孤立知识
- 查看知识断层
- 查看知识聚类

强调：图谱服务于理解，不做炫技动画。

## 6. 问 AI 页（Ask）

- 对话式问答
- 回答中标注：哪些是「知识库已有信息」、哪些是「AI 当前补充」
- 引用历史知识的来源时间与相关性说明

## 7. 复习页（Review）

- 复习计划列表（AI 挑选 + 原因说明）
- 复习会话：逐题作答，AI 即时评估
- 完成后的掌握度反馈

## 8. 我的画像页（Profile，只读）

- 职业、工作领域、关注方向、技术深度、兴趣、学习目标
- AI 学习建议：接下来学什么、哪些不需要深入
