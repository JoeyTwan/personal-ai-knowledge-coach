# 09 · 复习与出题机制

复习是第二个核心模块，目的是「判断用户真正掌握了什么」，而非简单刷题。

## 1. 题型（8 类）

| 题型 | 目的 | 示例 |
| --- | --- | --- |
| 选择题 | 低成本快速检测 | 面对这个场景哪种方案更合理 |
| 回忆题 | 验证能否想起 | 不看笔记解释什么是 X |
| 理解题 | 验证是否理解原理 | 为什么 X 会导致 Y |
| 对比题 | 验证辨析能力 | A 和 B 的核心区别 |
| 反例/辨析题 | 验证是否真懂 | 这个说法是否成立，为什么 |
| 应用题 | 验证迁移能力 | 遇到客户场景你会怎么用 |
| 关联题 | 验证关系建立 | 为什么 A 和 B 有关系 |
| 开放题 | 自由表达 | 谈谈你的理解 |

## 2. 动态难度

```
刚学完：简单回忆题
答对 → 理解题 → 关联题 → 应用题
答错 → 降低难度 → 回到原知识 → 解释 → 再测试
```

题目由 AI 针对用户当前认知状态即时生成，不是静态题库。

## 3. 选择题作为「认知体检」

隔一段时间用轻量选择题主动了解用户水平，判断：

- 是否知道这个领域
- 是否理解关键概念
- 能否把知识迁移到场景
- 是否只是记住了关键词

结果进入用户认知模型。

## 4. 错题系统与归因

错误不只记「错题 1」，要记录「为什么可能答错」：

| 归因 | 处理 |
| --- | --- |
| 遗忘 | 过一段时间再考 |
| 概念混淆 | 出对比题 |
| 关系没建立 | 出关联题 |
| 前置知识不足 | 推荐学习中间知识 |
| 理解错误 | 回到原知识再解释 |
| 应用错误 | 出场景题 |

这是知识教练与普通刷题产品的核心区别。

## 5. 间隔复习（初版简单算法）

```
新知识 → 初次检测 → 再检测 → 巩固 → 长间隔复习
```

维护字段：上次复习时间、答题结果、难度、遗忘风险、下次推荐时间。

## 6. 每周主动复习

每周 AI 主动挑选复习内容并说明原因，例如：

> 这周帮你挑了 12 个最值得复习的知识：5 个容易遗忘、3 个与最近工作相关、2 个关联还不牢、2 个最近更新过。

用户点击「开始本周复习」，系统逐题出题。

## 7. 复习触发方式

- 主动：「我想复习一下知识库」
- 定时：每周系统主动提醒
- 范围：全部 / 按分类 / 按时间 / 按主题 / 薄弱知识 / 最近知识
- 第一版允许用户控制，也允许 AI 自动推荐
