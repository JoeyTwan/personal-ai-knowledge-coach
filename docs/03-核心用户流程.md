# 03 · 核心用户流程

## 流程 A：学习与知识共创

```
用户输入「我今天学了 X」
  → AI 理解，识别事实/观点/经验/假设/结论，发现可能的问题
  → AI 追问、澄清、纠正（多轮讨论）
  → 双方达成共识
  → AI 生成最终知识内容
  → 用户选择：收录 / 继续讨论 / 修改后收录 / 放弃
  → 仅「收录」后正式入库
  → AI 自动分类、建立关系、更新知识网络、更新用户状态
```

## 流程 B：未来调用过去知识

```
用户提问「X 为什么会这样？」
  → 系统检索用户已有知识 + 相关关系 + 时间有效性 + 用户角色 + 掌握度
  → AI 找到历史知识，说明「你在某月某日记录过…」及为什么相关
  → 区分「已有知识」与「AI 补充」
```

## 流程 C：复习与掌握度验证

```
用户点击「开始复习」（或每周主动提醒）
  → AI 挑选复习内容并说明原因
  → 逐题生成（回忆 → 理解 → 关联 → 应用，动态升降）
  → 用户作答
  → AI 评估：记忆 / 理解 / 关联 / 应用分别如何
  → 更新掌握状态，错题归因
  → 调整复习计划，安排下次复习时间
```

## 流程 D：知识断层发现

```
系统分析用户已有知识 A → D 之间缺失的 B/C
  → 结合用户职业、目标、使用场景判断 C 是否值得学习
  → 值得：推荐学习；不值得：告知无需深入
```

## 流程 E：知识演化

```
同一公司/技术出现新信息
  → AI 识别为同一知识对象的更新
  → 保留历史版本，记录变化原因、来源、可信度变化
  → 更新当前版本与状态
```

## 流程 F：知识合并

```
系统发现重复/高度相似知识
  → AI 建议合并
  → 用户确认
  → 生成更完整的单一知识对象
```

## 全局原则

产品排序：用户真正学习和成长 ＞ 知识长期积累 ＞ 知识关系和调用 ＞ 掌握度和复习 ＞ 视觉展示 ＞ 炫技功能。
